# E-Commerce

เว็บไซต์ร้านเสื้อผ้า พัฒนาด้วย HTML, Tailwind CSS, DaisyUI และ JavaScript

## ฟีเจอร์

- หน้าแรกแสดงสินค้าเข้าใหม่และสินค้าขายดี
- หน้าร้านคัดกรองตามหมวดหมู่ ช่วงราคา คำค้นหา และเรียงลำดับสินค้าได้
- หน้ารายละเอียดสินค้า เลือกสี ไซส์ และจำนวนสินค้าได้
- ค้นหาสินค้าจากแถบนำทาง แล้วส่งต่อไปยังหน้าร้าน
- ตะกร้าสินค้าเพิ่ม ลดจำนวน หรือลบสินค้าได้ พร้อมคำนวณยอดรวม
- เก็บข้อมูลตะกร้าไว้ใน `localStorage` ของเบราว์เซอร์
- รองรับการแสดงผลบนมือถือและเดสก์ท็อป

## เครื่องมือ

- HTML5
- CSS3
- Tailwind CSS ผ่าน CDN
- DaisyUI ผ่าน CDN
- JavaScript (ES Modules)
- noUiSlider สำหรับตัวเลื่อนช่วงราคาในหน้าร้าน

## โครงสร้างโปรเจกต์

```text
.
├── index.html                 # หน้าแรก
├── shop.html                  # หน้ารายการสินค้าและตัวกรอง
├── product-detail.html        # หน้ารายละเอียดสินค้า
├── cart.html                  # ตะกร้าสินค้าและการสั่งซื้อ
├── brands.html                # หน้าแบรนด์
├── login.html                 # หน้าเข้าสู่ระบบ
├── style.css                  # สไตล์เพิ่มเติม
├── img/                       # รูปภาพและสินค้าต่าง ๆ
└── js/
    ├── products.js            # ข้อมูลสินค้า
    ├── render.js              # ฟังก์ชันสร้างการ์ดสินค้า
    ├── index.js               # การทำงานของหน้าแรก
    ├── product-list.js        # การค้นหา กรอง และเรียงสินค้า
    ├── product-detail.js      # การทำงานของหน้ารายละเอียดสินค้า
    ├── cart.js                # จัดการตะกร้าสินค้า
    └── seach.js               # ฟังก์ชันค้นหาและค้นหาบนมือถือ
```

## วิธีใช้งาน

- VS Code สามารถเปิด `index.html` ด้วยส่วนขยาย Live Server ได้เลย

## หน้าหลักของเว็บไซต์

| หน้า | URL | หน้าที่ |
| --- | --- | --- |
| หน้าแรก | `index.html` | แสดง Hero, สินค้าเข้าใหม่ และสินค้าขายดี |
| ร้านค้า | `shop.html` | ค้นหา กรอง และเรียงลำดับสินค้า |
| รายละเอียดสินค้า | `product-detail.html?id=1` | ดูรายละเอียดและเพิ่มสินค้าลงตะกร้า |
| ตะกร้าสินค้า | `cart.html` | จัดการรายการสินค้าและจำลองการสั่งซื้อ |
| แบรนด์ | `brands.html` | แสดงข้อมูลแบรนด์ |
| เข้าสู่ระบบ | `login.html` | หน้า Sign In |

## หมายเหตุ

- การสั่งซื้อเป็นการจำลอง เมื่อกด `Place Order` ระบบจะแจ้งผลสำเร็จและล้างข้อมูลตะกร้า
- ข้อมูลสินค้าอยู่ในไฟล์ `js/products.js` สามารถเพิ่มหรือแก้ไขรายการสินค้าได้จากไฟล์นี้
- ข้อมูลตะกร้าถูกบันทึกเฉพาะในเบราว์เซอร์และอุปกรณ์ที่ใช้งาน
